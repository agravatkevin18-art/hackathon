Slide 08 of 16 • Core Engine 2: Heuristic URL Engine Lexical Analysis & 1.8MB Bloom Filter
Lexical & Typosquatting Analysis

• Typosquatting detection using Levenshtein distance (e.g. sbi-online.xyz).

• Shannon entropy analysis detects random generated phishing domains.

• Immediate red-flag for suspicious TLDs (.xyz, .top, .live).

Compressed Bloom Filter & Local DB

• 1.8MB Bloom Filter allows O(1) instant offline lookups of 100k+ safe domains.

• Zero external DNS queries or server telemetry needed.

• Encrypted local SQLite cache stores localized threat rules.

Overlay Hijacking Defense
