01 • THE TARGET (PART 2)

OUR UNDERSTANDING & ARCHITECTURAL GAPS

FAILURES OF CURRENT SOLUTIONS
  • • High Network Latency: Cloud API threat lookups take 2.0 to 4.5 seconds—too slow to stop an impulsive tap.
  • • Offline Vulnerability: When traveling, roaming, or on poor connectivity, cloud security ceases to exist.
  • • Massive Privacy Violations: Sending personal SMS messages and copied URLs to third-party servers breaches confidentiality.
  • • Battery & Data Overhead: Continuous HTTP polling severely drains battery life on budget smartphones.
WHY SOLVE IT ON-DEVICE NOW?
  • • DPDP Act 2023 Compliance: India's strict personal data protection law demands private communications stay on device.
  • • Sub-50ms Response: Modern edge processors can run quantized neural networks locally with near-zero latency.
  • • Zero Attack Surface: Since no data ever leaves the handset, man-in-the-middle interception is impossible.
  • • Universal Access: Operates seamlessly in flight mode, rural areas, or offline environments with zero recharge cost.

03 • THE ARSENAL (PART 1)

KEY FEATURES: NLP & URL HEURISTICS

FEATURE 01: ON-DEVICE NLP SCANNER
  • • TinyBERT NLP Transformer quantized to INT8 precision with a compact 14.8MB footprint.
  • • Trained specifically on 15,000+ Indian cyber scam samples (electricity bill, KYC expiry, UPI lottery).
  • • Detects psychological panic triggers: 'Urgent Action Required', 'Account Suspended in 24h'.
  • • Sub-35ms inference speed directly on CPU without requiring an external NPU or GPU.
FEATURE 02: OFFLINE URL ENGINE
  • • Typosquatting Detection: Employs Levenshtein Distance against top 500 Indian banking domains.
  • • Detects deceptive lookalikes: Flags 'sbi-kyc-update.xyz', 'hdfc-verification.top'.
  • • 1.8MB Bloom Filter: Instant O(1) hash check for known verified legitimate domains.
  • • Zero External Query: Intercepts malicious links locally before the browser can resolve DNS.
